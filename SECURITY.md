# Security policy

This repository is an unofficial Discord client. Please do not include account credentials, authentication tokens, private messages or private attachment URLs in issue reports.

## Reporting vulnerabilities

For a suspected vulnerability in DTEW Cord's code, contact the maintainers through the project's GitHub security reporting facilities rather than publishing exploit details in a public issue. Include the affected component, impact, reproduction steps that do not expose real user data, and a proposed mitigation if available.

## Scope

Security-sensitive areas include authentication and credential storage, REST/Gateway transport, local persistence, attachment handling, and native platform integrations.

This policy does not imply that using an unofficial client is permitted by Discord or that account enforcement can be prevented. See `docs/threat-model.md` and `docs/discord-compatibility.md`.
