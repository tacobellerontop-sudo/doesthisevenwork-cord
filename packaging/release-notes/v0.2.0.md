DTEW Cord v0.2.0 brings a new icon, its own theming system, and a cleanup of what was left over from Serein.

> DTEW Cord is not endorsed by Discord. Signing in a normal account with an unofficial client may break Discord's Terms of Service and can lead to account enforcement.

### New
- A new DTEW Cord icon replaces the inherited Serein logo, in the window, taskbar, tray and notifications.
- Themes: pick from the built-in DTEW Cord light and dark, Eclipse, Slate, Nightfall, Ember, Verdant and Afterglow themes, or make your own in Settings › Appearance. Custom themes have a live preview editor and can be imported and exported as small JSON files.
- Smooth scrolling: each mouse wheel notch now glides over about 180 ms instead of jumping. Turn it off in settings to scroll instantly.
- The sign-in screen can be dragged from anywhere, not only its header.

### Removed
- The extension system inherited from Serein: the Extensions and Themes pages, plugins, the extension catalog and the plugin API proxy. Themes now come from the theming system above. Extension themes and plugins from v0.1.0 no longer load.
- The "Early preview" label and the DEV / OFFLINE PREVIEW tags in the title bar. Update notices still show there.

### Known issues
- The sign-in drag change has not been tried on a real Windows desktop yet. If dragging the sign-in window misbehaves, please open an issue.

### Download
- Windows: dtewcord-v0.2.0-Windows-X64.zip. Extract it and run dtewcord.exe; run install-notifications.ps1 once for system notifications. Installs of v0.1.0 update themselves from this repository's releases.

### Not included yet
- The Slint client in apps/slint is not packaged in this release.
