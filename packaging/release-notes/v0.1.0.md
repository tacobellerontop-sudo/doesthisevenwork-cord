First release of DTEW Cord, an unofficial Discord client written in Rust and forked from Serein.

> DTEW Cord is not endorsed by Discord. Signing in a normal account with an unofficial client may break Discord's Terms of Service and can lead to account enforcement.

### New
- Rebranded from Serein to DTEW Cord, with its own app id, keychain entry and data folder.
- The built-in updater and the extension catalog now use this repository's releases.
- Settings rows, the profile preview and the title bar lay out correctly at every width.
- Picking a server with nothing you can open shows the server instead of the old conversation.

### Downloads
- Linux: dtewcord-v0.1.0-Linux-X64.AppImage. It needs GTK 3 and 4, WebKitGTK and GStreamer from your distribution, and updates itself in place.
- Windows: dtewcord-v0.1.0-Windows-X64.zip. Extract it and run dtewcord.exe; run install-notifications.ps1 once for system notifications.
- macOS: dtewcord-v0.1.0-macOS-ARM64.zip or -X64.zip. The app is ad-hoc signed, not notarized, so open it with right-click > Open the first time; in-app updates on macOS need a Developer ID signed release.

### Not included yet
- The Slint client in apps/slint is not packaged in this release.
